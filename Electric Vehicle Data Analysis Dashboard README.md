# Electric Vehicle Data Analysis Dashboard 

This project is a Tableau-based data visualization and analysis of electric vehicles (EVs) in the United States, using publicly available data from Kaggle. The dashboard provides insights into EV adoption trends, vehicle performance, and other metrics.

The goal of this project was to explore and visualize trends in the electric vehicle market. Using Tableau, I created an interactive dashboard that allows users to dive into various metrics and gain a better understanding of the growing EV landscape.

## Key Insights
	•	Average Electric Range: Analyzed and visualized the average electric range over time, broken down by vehicle type.
	•	BEV vs PHEV Distribution: Compared the number of Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
	•	EV Growth Over Time: Identified key growth periods and trends in EV adoption.
	•	Top Vehicles: Displayed the most common EV models and makes by volume.
	•	Filterable Views: Included multiple filters such as model year, make, and location to enable customized exploration.

## BEVs vs. PHEVs: What’s the Difference?
	•	Battery Electric Vehicles (BEVs) are fully electric and run solely on battery power. They do not have a gasoline engine and must be plugged in to recharge. Examples include the Tesla Model 3.
	•	Plug-in Hybrid Electric Vehicles (PHEVs) combine a gasoline engine with an electric battery. They can operate on electric power for short distances and switch to gas for longer trips. Examples include the Toyota Prius Prime and Chevrolet Volt.

## Dataset

The dataset used in this project was obtained from Kaggle:
(https://www.kaggle.com/datasets/ratikkakkar/electric-vehicle-population-data)

This dataset includes detailed records of electric vehicles registered primarily in Washington State, with features such as vehicle type, make, model year, electric range, and more.
